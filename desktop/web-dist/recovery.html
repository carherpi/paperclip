Paperclip could not open its local service

Checking the local service…

Paperclip keeps work in ~/.paperclip/instances/desktop; this recovery screen does not change it.

  1. Install Node.js 24.11 or newer if it is not already installed.
  2. In Terminal, run npx paperclipai@latest install --yes.
  3. Run paperclipai service start --instance desktop, then reopen this app.

For diagnostics, run paperclipai service status --instance desktop or paperclipai service logs --instance desktop.
