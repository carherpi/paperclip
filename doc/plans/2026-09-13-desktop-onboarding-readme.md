# Desktop onboarding README

## Goal

Give a new macOS operator a short, accurate path from the Paperclip desktop
application to their first project and task.

## Steps

1. Add a dedicated README beside the desktop package.
   Verify: it distinguishes the desktop wrapper from upstream Paperclip.
2. Document first launch, local data, subscription authentication, everyday
   use, and safe shutdown and restart commands.
   Verify: every command and path matches the current desktop instance.
3. State the MVP limits so operators do not assume unavailable workflow,
   Telegram, Keychain, or sandbox features are present.
   Verify: the limits agree with `doc/desktop-subscription-mvp.md`.
